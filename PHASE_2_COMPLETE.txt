HOW TO USE THE INCOME TRACKING API
================================================================================

1. AUTHENTICATE:
   POST /api/v1/auth/login
   Body: { "email": "user@example.com", "password": "password" }
   Response: { "access_token": "jwt_token", "token_type": "bearer" }

2. CREATE INCOME SOURCE:
   POST /api/v1/income/sources
   Header: Authorization: Bearer {access_token}
   Body: {
     "name": "Monthly Salary",
     "type": "SALARY",
     "frequency": "MONTHLY",
     "amount": 5000,
     "start_date": "2026-01-01",
     "is_recurring": true,
     "is_taxable": true,
     "auto_tax_calculation": true,
     "tax_rate": 20.0
   }

3. RECORD INCOME:
   POST /api/v1/income/history
   Header: Authorization: Bearer {access_token}
   Body: {
     "income_source_id": "uuid_from_step_2",
     "amount": 5000,
     "received_date": "2026-01-31",
     "tax_amount": 1000,
     "is_manual_entry": true
   }

4. GET MONTHLY SUMMARY:
   GET /api/v1/income/summary/2026/1
   Header: Authorization: Bearer {access_token}
   Response: {
     "total_income": 5000,
     "total_tax": 1000,
     "net_income": 4000,
     "recurring_income": 5000,
     "one_time_income": 0,
     "source_count": 1,
     "record_count": 1
   }

5. GET ANNUAL STATS:
   GET /api/v1/income/stats?year=2026
   Header: Authorization: Bearer {access_token}
   Response: {
     "total_annual_income": 60000,
     "average_monthly_income": 5000,
     "predicted_next_month": 5000,
     "total_tax_paid": 12000,
     "net_annual_income": 48000,
     "recurring_income_count": 1,
     "one_time_income_count": 0,
     "top_source_name": "Monthly Salary",
     "top_source_amount": 60000
   }
